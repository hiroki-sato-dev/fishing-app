# 2. 機能要件

## 2.1 ユーザー管理・認証機能

### 2.1.1 ユーザー登録

#### 登録フロー
1. `/auth` でメールアドレス・パスワードを入力し Cognito アカウントを作成
2. メール認証コードで確認
3. ログイン後、DBユーザーが未作成の場合は `/user/setup` へ自動リダイレクト
4. プロフィール設定を入力して完了 → `/home` へ遷移

#### 入力項目
- **必須項目（/user/setup で入力）**: 名前
- **任意項目（/user/setup で入力）**: プロフィール画像、釣り歴、メインの釣りもの
- **制限事項**:
  - ユーザー名: 16文字以内
  - プロフィール画像: Twitter同等のファイルサイズ制限

#### /user/setup のアクセス制御
- Cognito 認証済み・DBユーザー未作成のユーザーのみアクセス可能
- DBユーザーが既に存在する場合は `/home` へリダイレクト
- 未ログインの場合は `/auth` へリダイレクト

### 2.1.2 認証システム
- AWS Cognito + Amplifyによる認証

#### アクセス制御ポリシー

**ゲスト（未ログイン）でも閲覧できるページ**
| ページ | 内容 |
|---|---|
| ホーム (`/home`) | 投稿一覧・地図表示 |
| 投稿詳細 (`/post/[id]`) | 投稿内容・コメント一覧の閲覧 |
| ユーザープロフィール (`/user/[id]`) | 公開アカウントのプロフィール・投稿閲覧 |
| ログイン・登録 (`/auth`) | 認証画面 |

**ログインが必要なアクション**
| アクション | 内容 |
|---|---|
| 投稿作成 | `/post/new` ページへのアクセス・投稿送信 |
| いいね | 投稿へのいいね・取り消し |
| コメント | コメント投稿・編集・削除 |
| フォロー | ユーザーのフォロー・フォロー解除 |
| 釣りエリア作成 | 地図上でのエリア新規作成 |

**実装方針**
- ページ自体はゲストでもアクセス可能
- ログインが必要なアクション実行時に `/auth` へ誘導
- Server Action 内で認証チェックを行いエラーを返す

### 2.1.3 プライバシー設定
- **公開アカウント**: 即座にフォロー可能、投稿は全体公開
- **鍵付きアカウント**: フォロー申請→承認制、投稿はフォロワーのみ表示

## 2.2 釣りエリア管理機能

### 2.2.1 釣りエリア（FishingArea）作成
- **エリア作成**: 地図上のタップ/クリックで円形エリアを作成
- **エリア情報**: 
  - 名前（32文字以内、任意）
  - 説明（256文字以内、任意）
  - 中心座標（緯度・経度）
  - 半径（50-1000m、デフォルト200m）
- **重複チェック**: 既存エリアとの重複判定・統合提案
- **作成者**: エリアを作成したユーザーを記録

### 2.2.2 釣りエリア選択・表示
- **既存エリア選択**: タップ位置に既存エリアがある場合は選択UI表示
- **新規エリア作成**: 既存エリアがない場合はプレビュー円表示→作成確認
- **エリア情報表示**: エリア名、投稿数、作成者、説明等
- **統計表示**: エリア内の投稿数、人気度等

## 2.3 投稿機能

### 2.3.1 投稿作成
- **投稿内容**: テキスト（256文字以内、必須）
- **画像**: 最大4枚まで添付可能（任意）
- **位置情報**: 以下のいずれかを選択
  - **釣りエリア**: 地図上で既存エリア選択または新規作成
  - **個別位置**: 従来通りの緯度・経度指定（下位互換）
- **投稿時間**: 自動記録

### 2.3.2 投稿管理
- **編集**: 投稿者本人のみ可能（釣りエリア・位置情報は編集不可）
- **削除**: 投稿者本人のみ可能
- **公開範囲**: アカウント設定に準拠

### 2.3.3 投稿表示
- **一覧表示**: 時系列順（最新順）
- **地図表示**: 釣りエリア円形表示（従来のピン表示も併用）
- **フィルタリング**: ズームレベルに応じた表示制御
- **エリア内投稿**: エリアタップで該当エリア内の投稿一覧表示

## 2.3.4 ユーザープロフィールページ

### `/user/[id]` - 公開プロフィールページ
- **表示内容**: ユーザー名、アイコン、自己紹介、釣り歴、メインの釣りもの
- **統計情報**: フォロワー数、フォロー中数、投稿数
- **投稿一覧**: そのユーザーの投稿を時系列で表示
- **フォローボタン**: ログイン済みかつ他人のプロフィールの場合に表示
- **アクセス制御**: ゲストでも閲覧可能（公開アカウントのみ）

### `/user/settings` - プロフィール編集ページ
- **編集可能項目**: 名前、自己紹介、プロフィール画像URL、釣り歴、メインの釣りもの
- **アクセス制御**: ログイン必須（未ログインの場合は `/auth` へリダイレクト）
- **バリデーション**: 名前16文字以内など `/user/setup` と同様

## 2.4 ソーシャル機能

### 2.4.1 フォロー機能
- **公開アカウント**: 即座にフォロー
- **鍵付きアカウント**: 申請→承認制
- **フォロー一覧**: フォロー中・フォロワー表示

### 2.4.2 いいね機能
- 投稿に対するいいね
- いいね数の表示
- 自分がいいねした投稿の管理

### 2.4.3 コメント機能
- 投稿に対するコメント投稿
- コメント一覧表示
- コメントの編集・削除（投稿者のみ）

## 2.5 地図機能

### 2.5.1 地図表示
- **初期表示**: ユーザーの現在地
- **地図サービス**: Google Maps JavaScript API
- **操作**: ズーム、パン、円形エリア・ピンタップ

### 2.5.2 釣りエリア円形表示
- **円形エリア**: 半径200m（設定可能）の円形で表示
- **エリア情報**: 円内に投稿数、主要魚種アイコン等を表示
- **クラスタリング**: 近接エリアの統合表示、ズームで分離
- **ズーム連動**: ズームレベルに応じた表示制御
- **全投稿対応**: 既存の個別位置投稿も最寄りエリアに自動統合表示

### 2.5.3 インタラクティブ機能
- **エリアタップ**: 釣りエリア情報・投稿一覧表示
- **地図タップ**: 新規投稿時のエリア作成・選択UI
- **地図移動**: 表示エリアに応じたデータ更新
- **現在地機能**: ユーザー位置への自動移動

### 2.5.4 投稿作成時の地図機能
- **インタラクティブ選択**: 地図タップで位置・エリア選択
- **既存エリア判定**: タップ位置の既存エリア自動検出
- **プレビュー表示**: 新規エリア作成時のプレビュー円表示
- **確認UI**: エリア選択・作成の確認ダイアログ
