# 9. 開発チケットバックログ

## 📋 全体チケット管理

### チケット番号体系
- **INFRA-XXX**: インフラ・基盤整備
- **USER-XXX**: ユーザー管理機能
- **POST-XXX**: 投稿機能
- **SOCIAL-XXX**: ソーシャル機能
- **MAP-XXX**: 地図機能
- **SEARCH-XXX**: 検索・絞り込み機能
- **FISH-XXX**: 釣り特化機能
- **UI-XXX**: UI/UX改善
- **TEST-XXX**: テスト・品質改善

### 優先度定義
- 🔴 **P0-Critical**: ブロッカー、リリースに必須
- 🟠 **P1-High**: 高優先度、早期実装が必要
- 🟡 **P2-Medium**: 中優先度、計画通りに実装
- 🟢 **P3-Low**: 低優先度、余裕があれば実装

### 工数見積もり基準
- **XS**: 0.5日（4時間以内）
- **S**: 1日（1営業日）
- **M**: 2-3日（2-3営業日）
- **L**: 4-5日（1週間程度）
- **XL**: 1-2週間（要分割検討）
