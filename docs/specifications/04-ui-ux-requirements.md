# 4. UI/UX要件

## 4.1 デザインガイドライン

### 4.1.1 基本コンセプト
- **シンプルで直感的**: 釣り初心者でも迷わず使える操作性
- **自然な色合い**: 水や自然をイメージした落ち着いた色調
- **モバイルファースト**: スマートフォンでの使用を最優先

### 4.1.2 カラーパレット
- **プライマリ**: ブルー系（`#3B82F6`）- 水をイメージ
- **セカンダリ**: グレー系（`#6B7280`）- 落ち着いた印象
- **アクセント**: 釣りに関連する自然色（緑、オレンジなど）

## 4.2 レスポンシブデザイン

### 4.2.1 対応デバイス
- **スマートフォン**: 375px〜 （iPhone SE以上）
- **タブレット**: 768px〜 （iPad以上）
- **デスクトップ**: 1024px〜 （PC画面）

### 4.2.2 ブレイクポイント（MUI 準拠）
| ブレイクポイント | 幅 | 用途 |
|---|---|---|
| `xs` | 0px〜 | スマートフォン基本スタイル |
| `sm` | 600px〜 | 大きめスマートフォン・小タブレット |
| `md` | 900px〜 | タブレット |
| `lg` | 1200px〜 | デスクトップ（2カラムレイアウト切り替え） |
| `xl` | 1536px〜 | 大画面デスクトップ |

### 4.2.3 レイアウト方針
- **ホーム画面**: `lg` 以上で地図（左8/12）+ 投稿フィード（右4/12）の2カラム
- **ユーザー詳細**: `md` 以上で釣りポイント地図（左 340px、sticky）+ 投稿グリッド（右、`lg` 以上で2列）
- **文字サイズ**: `xs`/`sm`/`md` ごとに段階的にスケーリング（固定サイズ禁止）
- **カード padding**: `p: { xs: 2, sm: 2.5〜3 }` でモバイルを引き締め
- **ページ上部余白**: `pt: { xs: 8, md: 10 }`（AppBar 高さ: xs=56px / sm+=64px）

## 4.3 画面構成・ナビゲーション

### 4.3.1 共通レイアウト
- **ヘッダー**: ロゴ、ユーザーアイコン、通知アイコン
- **メイン**: 各ページのコンテンツエリア
- **ナビゲーション**: 下部固定（モバイル）/ サイドバー（デスクトップ）

### 4.3.2 主要ページ構成
1. **ホーム画面** (`/home`): 地図 + 投稿フィード（「最新の釣果」/「フォロー中」タブ切り替え）
2. **投稿作成** (`/post/new`): フォーム + 位置情報取得
3. **投稿詳細** (`/post/[id]`): 投稿内容・いいね・コメント
4. **いいね一覧** (`/post/[id]/likes`): 投稿者本人のみ閲覧可
5. **プロフィール** (`/user/[id]`): ユーザー情報 + 投稿履歴 + フォロー/フォロワー数
6. **フォロー管理** (`/user/[id]/follows`): フォロー・フォロワー一覧（タブ切り替え）
7. **設定** (`/user/settings`): プロフィール編集

## 4.4 インタラクション・フィードバック

### 4.4.1 ローディング状態
- **投稿読み込み**: スケルトンローダー表示
- **地図読み込み**: ローディングスピナー
- **画像アップロード**: プログレスバー

### 4.4.2 エラーハンドリング
- **ネットワークエラー**: 再試行ボタン付きメッセージ
- **位置情報エラー**: 手動入力への誘導
- **バリデーションエラー**: フィールド単位でのエラー表示

### 4.4.3 成功フィードバック
- **投稿完了**: トーストメッセージ + 自動遷移
- **いいね**: Optimistic UI（`useState`）でカウント即時更新（未ログイン時はツールチップで誘導）
- **フォロー**: ボタンステータス変更（"フォロー" / "フォロー中" / "リクエスト済み"）

### 4.4.4 フォローバッジ
- 自分がフォローしているユーザーのアバターに青ドットバッジを表示
- 表示箇所: ホームフィード投稿一覧・いいね一覧ページ・フォロー一覧ページ

### 4.4.5 コメントAvatarGroup
- コメントしたユーザーのアバターをMUI AvatarGroup（最大3件、重ね表示）でコメント数アイコン横に表示
- ホームフィード・投稿詳細ページ両方に対応

## 4.5 アクセシビリティ

### 4.5.1 基本対応
- **キーボードナビゲーション**: Tab順序の最適化
- **スクリーンリーダー**: 適切なaria-label設定
- **コントラスト**: WCAG 2.1 AA準拠

### 4.5.2 ユーザビリティ
- **タッチターゲット**: 最小44px以上
- **フォントサイズ**: 最小16px（モバイル）
- **操作フィードバック**: 視覚的・触覚的フィードバック

## 4.6 地図UI要件

### 4.6.1 地図操作
- **ズーム**: ピンチ・ダブルタップ・ボタン操作対応
- **パン**: ドラッグ操作対応
- **現在地**: 現在地ボタンでの自動移動

### 4.6.2 ピン・エリア表示
- **釣りエリア**: 青色の円形（`google.maps.Circle`）で範囲を表示
- **マーカー**: `AdvancedMarker` + カスタム HTML で投稿数バッジ付き赤丸を表示
- **現在地マーカー**: 赤丸アイコンで現在地を表示
- **選択ハイライト**: 選択済みエリアを緑（既存）/オレンジ（新規作成予定）でオーバーレイ
- **プレビュー円**: 新規エリア作成ダイアログ表示中に半径200mの緑円をプレビュー表示
- **現在地ボタン**: `MapControl`（TOP_RIGHT）に FAB ボタンとして配置
